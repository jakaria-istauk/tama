Everything a team board needs

Simple to start with, and enough depth for real projects.

Kanban boards

Projects, boards, lists and cards, with drag and drop.

Real-time collaboration

Every change shows up for everyone at once. No refresh.

Rich cards

Markdown, attachments, comments, tasks, labels, custom fields, due dates and a stopwatch.

Notifications

Send updates to over 100 services through Apprise.

Webhooks and REST API

Build your own integrations on a documented API.

Secure sign-in

Google sign-in, two-factor authentication with recovery codes, and personal API keys.

Your AI assistant, on your board

Tama has a built-in Model Context Protocol server. Connect an assistant and ask it to plan a sprint, sort a backlog or write up a card. It works as you, so it sees and changes only what you can.

  • Claude and ChatGPT connect through OAuth, with a consent screen.
  • Coding agents connect with a personal API key.
  • See and disconnect connected apps at any time.
Claude ChatGPT Claude Code Codex Cursor VS Code Gemini CLI Windsurf

Running in a few minutes

All you need is a server with Docker and Compose.

Get the code

Clone the repository.

git clone https://github.com/jakaria-istauk/tama.git
cd tama

Configure

In docker-compose.yml, set BASE_URL and a random SECRET_KEY.

openssl rand -hex 32

Start it

Start Tama and create the first admin.

docker compose up -d --build
docker compose run --rm tama \
  npm run db:create-admin-user

More ways to deploy: Kubernetes, Cloudflare Tunnel
